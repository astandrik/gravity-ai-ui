# Gravity AI UI

Website scaffold using the same frontend stack as `codex-pets`.

## Stack

- Next.js 16 App Router, React 19, TypeScript strict
- Gravity UI + SCSS
- ESLint 9 + Vitest
- npm with Node 24

## Development

```bash
nvm use 24
npm install
npm run dev -- --port 3000
```

Open `http://localhost:3000`.

## Commands

```bash
npm run lint
npm test
npm run typecheck
npm run build
```
