## MCP Directory Submission Copy

Name: Gravity AI UI

Category: AI UI generator, MCP server, developer tools

Short description:
Gravity AI UI is an AI UI generator for agents. It turns prompts into validated A2UI component trees, renders them with trusted Gravity UI components, and exposes MCP, OpenAPI, markdown docs, public gallery pages, and React export artifacts.

Long description:
Gravity AI UI helps agents generate, inspect, refine, and reuse product-interface drafts. The public remote MCP server supports interface search, interface retrieval, generation, and refinement. Generated output is constrained to a structured A2UI-style component tree and rendered through Gravity UI rather than arbitrary JSX or HTML. Agents can discover the service through llms.txt, OpenAPI, markdown docs, OAuth metadata, MCP server-card metadata, and public gallery pages.
